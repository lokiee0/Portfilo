PortSentinel
PortSentinel is a lightweight port scan detector that monitors network traffic to detect TCP port scans in real-time. Built with Python and Scapy library for packet capturing and analysis, it successfully detects port scanning attempts with dynamic thresholds and alert logging. This tool helps network administrators identify and mitigate reconnaissance attacks quickly, providing essential security monitoring capabilities for network infrastructure.
Weather Forecast CLI
A command-line weather forecast tool that fetches and displays current and forecasted weather data from multiple cities. Built using Python, OpenWeatherMap API, and Requests library, it provides accurate weather information via CLI interface. This tool helps users quickly get weather updates without requiring a graphical user interface, demonstrating API integration and CLI development skills.
Security Automation Scripts
A collection of Python security automation scripts developed during my cybersecurity internship at Senchola Technology Solutions. These scripts automate incident response workflows for simulated attacks, vulnerability scanning, and network security assessments. The tools integrate with Wireshark and Nmap for comprehensive security analysis and reporting.
Network Analysis Suite
